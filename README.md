# water-tracker-app

Одностраничное приложение-трекер воды. Репозиторий хранит HTML/Vite prototype и задачи по базовой UX-логике вроде кнопки «выпить бутылку» и исправления ошибок.

## Что внутри

| Путь | Роль |
|---|---|
| `index.html` | entrypoint приложения |
| `water_tracker_одностраничное_приложение.html` | standalone HTML-версия |
| `vercel.json` | deploy-настройки |
| GitHub Issues | баги и UX-задачи приложения |

## Как работать

- Проверять UI вручную после изменения поведения кнопок.
- Не усложнять архитектуру без необходимости: это маленький single-page app.
- Если задача из issue не воспроизводится, сначала зафиксировать фактическое поведение в комментарии.
